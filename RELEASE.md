# Tokyo Racing - Release Notes v1.0.0

## 🎮 Welcome to Tokyo Racing!

Tokyo Racing is now available to play directly in your browser. No installation required!

### 🚀 Getting Started

#### Online
1. Visit: [https://danie978.github.io/tokyo-racer/game.html](https://danie978.github.io/tokyo-racer/game.html)
2. Click "START RACE" or "FREE ROAM"
3. Start driving!

#### Local
```bash
# Clone the repository
git clone https://github.com/danie978/tokyo-racer.git
cd tokyo-racer

# Start local server
python -m http.server 8000

# Open browser to http://localhost:8000/game.html
```

### 🎮 Game Modes

#### Race Mode
- Compete in timed races

### 🕹️ Controls

**Keyboard & Arrow Keys:**
- `W` or `Arrow Up` - Accelerate
- `S` or `Arrow Down` - Reverse
- `A` or `Arrow Left` - Turn Left
- `D` or `Arrow Right` - Turn Right
- `SPACE` - Brake
- `P` - Pause
- `ESC` - Return to Menu

### 📊 HUD Information

**Top Left:**
- Current Speed (km/h)
- RPM Counter
- Current Gear

**Top Right:**
- Elapsed Time
- Distance Traveled
- FPS Counter

**Bottom Left:**
- Race Position
- Current Lap Time

**Bottom Right:**
- Minimap with player position
