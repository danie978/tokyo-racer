# 🏎️ Tokyo Open-World Racing - Mobile Game Prototype

## 📱 Überblick

Tokyo Open-World Racing ist ein revolutionärer Mobile-Rennspiel-Prototyp für Android und iOS mit hochrealistischer Grafik, Physics und einer gigantischen offenen Welt.

## ✨ Features

### Grafik & Technologie
- 🎨 **Hochrealistische Grafik**: PBR-Materialien, Raytracing, HDR-Beleuchtung
- ⚡ **Performance**: 60 FPS auf High-End, 45 FPS auf Mid-Range Geräten
- 🌍 **Offene Welt**: 50+ km² nahtlose Tokio-Karte ohne Ladebildschirme
- 🎥 **Dynamische Umgebung**: Echtzeitwetter, Tag-/Nachtwechsel

### Gameplay
- 🏁 **Race Mode**: Klassische Rennen gegen KI oder online
- ⏱️ **Time Trial**: Bezwinge deine Bestzeit
- 🌀 **Drift Challenge**: Sammle Punkte durch geschicktes Driften
- 🛣️ **Free Roam**: Erkunde Tokio ohne Einschränkungen
- 👥 **Multiplayer**: Bis zu 8 Spieler gleichzeitig
- 🏆 **Career Mode**: Aufstieg vom Amateur zum Pro

### Fahrzeuge
- **Nissan GT-R R35** (550 PS, 2.7s 0-100)
- **Toyota Supra A90** (340 PS, 3.8s 0-100)
- **Mazda RX-7 FC3S** (280 PS, 4.2s 0-100)

### Physik
- 🚗 Pacejka-Reifenmodell
- 🌬️ Realistische Aerodynamik
- 🔧 Detaillierte Federung & Bremsensystem
- 💥 Schadensmodell

## 🛠️ Tech Stack

- **Engine**: Unity 2022 LTS
- **Rendering**: HDRP mit Raytracing
- **Scripting**: C# & .NET
- **Audio**: FMOD Studio
- **Netzwerk**: Netcode für GameObjects
- **Backend**: PlayFab
- **UI**: TextMesh Pro

## 🎮 Installation

### Voraussetzungen
```bash
- Unity 2022 LTS
- HDRP Package
- Netcode for GameObjects
- PlayFab SDK
- TextMesh Pro
```

### Projekt klonen
```bash
git clone https://github.com/danie978/tokyo-racer.git
cd tokyo-racer
```

### Setup
1. Öffne das Projekt in Unity 2022 LTS
2. Importiere alle erforderlichen Packages
3. Lade die MainMenu Szene
4. Drücke Play zum Testen

## 🚀 Build

### Android
```
File > Build Settings
Plattform: Android
Scene: MainMenu, CityHub, RaceStart
Build
```

### iOS
```
File > Build Settings
Plattform: iOS
Scene: MainMenu, CityHub, RaceStart
Build
```
